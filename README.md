# Steward

A World of Warcraft: Forever add-on (made for client 1.60.1). It walks you through levelling: a guide with arrows and a planned route, quest pick-ups and hand-ins, travel directions (flights, boats, the tram, following a friend), vendor and trainer chores, and LEVEL UP posters for some race and class pairs.

## Install

1. **[Download Steward.zip](Steward.zip?raw=1)** (version 0.80.0, 24 MB). If it opens a page instead, press the download button on that page.
2. Unzip it into your game's add-on folder:
   `World of Warcraft\_forever_\Interface\AddOns\`
   You should end up with `AddOns\Steward\Steward.toc` (not `AddOns\Steward\Steward\...`).
3. Start the game (or restart it if it was running), and make sure **Steward** is ticked in the AddOns list on the character screen.

The first time you log in, a short setup asks how you want to level and what Steward should do for you. Change any of it later in Esc > Options > AddOns > **Steward** (where you can also run the setup again).

## Updating

Close the game, delete the old `AddOns\Steward` folder, and unzip the new release in its place.
