# Steward

A World of Warcraft: Forever add-on (made for client 1.60.1). It walks you through levelling: a guide with arrows and a planned route, quest pick-ups and hand-ins, travel directions (flights, boats, the tram, following a friend), vendor and trainer chores, and LEVEL UP posters for some race and class pairs.

## Install

1. **[Download Steward.zip](Steward.zip?raw=1)** (version 0.89.8, 24 MB). If it opens a page instead, press the download button on that page.
2. Unzip it into your game's add-on folder:
   `World of Warcraft\_forever_\Interface\AddOns\`
   You should end up with `AddOns\Steward\Steward.toc` (not `AddOns\Steward\Steward\...`).
3. Start the game (or restart it if it was running), and make sure **Steward** is ticked in the AddOns list on the character screen.

The first time you log in, a short setup asks how you want to level and what Steward should do for you. Change any of it later in Esc > Options > AddOns > **Steward** (where you can also run the setup again).

## Updating

**The easy way:** **[download StewardUpdater.exe](StewardUpdater.exe?raw=1)** once, keep it anywhere (your Desktop is fine), and double-click it whenever you want the newest Steward. It finds your AddOns folder, says which version you have and which is newest, and if there's a newer one downloads it and swaps it in. Your Steward settings are kept (WoW keeps them in its `WTF` folder, which the updater never touches). If WoW is open, restart it afterwards.

- The first time, Windows may say "Windows protected your PC" because the program isn't signed: press **More info**, then **Run anyway**.
- If it can't find your game, it asks once for your WoW folder (the one with `_forever_` in it) and remembers it.
- If it says Windows wouldn't let it write to the folder, right-click it and choose **Run as administrator**.
- Its source is in the `updater` folder here.

**By hand:** close the game, delete the old `AddOns\Steward` folder, and unzip the new release in its place.
